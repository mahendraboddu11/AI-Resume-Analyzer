# AI Resume Analyzer

An AI-based Resume Analyzer built using Python and Streamlit that compares a candidate's resume with a job description and provides a resume match score.

## 🚀 Live Demo

https://ai-resume-analyzer-entmvi8vtneaezfecawfv.streamlit.app/

## 📌 Features

- Upload resume in PDF format
- Enter a job description
- Extract text from resumes
- Identify matching skills
- Identify missing skills
- Calculate skill match percentage
- Calculate NLP similarity score
- Generate overall resume match score
- Provide resume improvement insights

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF2
- Natural Language Processing
- Python SequenceMatcher
- Regular Expressions

## ⚙️ How It Works

1. Upload your resume in PDF format.
2. Paste the target job description.
3. The application extracts and cleans the resume text.
4. Required skills are compared with the skills found in the resume.
5. NLP similarity is calculated between the resume and job description.
6. The system generates an overall match score.
7. Matching and missing skills are displayed.

## 📊 Analysis Results

The application provides:

- Overall Match Score
- NLP Similarity Score
- Skill Match Score
- Matching Skills
- Missing Skills
- Resume improvement recommendations
